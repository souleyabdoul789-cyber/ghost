# Archive historique — G 0.3.1

Ces distributions sont conservées pour référence historique. Elles contiennent l'ancien moteur et l'ancienne structure ABI `Tensor` de G 0.3.1. **Ne pas installer ce wheel avec les sources 0.4.0.** La version 0.4.0 étend la structure native et doit compiler son propre `libg.so` sur la machine cible via `./build.sh` ou `pip install .`.
