ÉTAT DU PRÉ-ENTRAÎNEMENT RÉEL
-----------------------------
Aucun téléchargement réel de FineWeb2-HQ ni aucun run GitHub Actions n'a
été lancé depuis cet environnement. Le nouveau dépôt dédié `ghost` doit être
créé vide sous le compte GitHub du propriétaire avant publication.
Le script `scripts/publish_training_branch.sh` pousse une branche isolée
`pretraining/0.6.2` vers un remote dont le nom doit être `ghost` ; il refuse
tout remote pointant vers l'ancien dépôt `G` et ne force jamais la branche.

LIMITES
-------
Ce pilote emploie un petit Transformer float32 sur CPU, sans backend GPU.
Le pré-entraînement causal apprend à prédire le prochain token ; il ne
confère pas automatiquement la capacité d'utiliser un navigateur ou un
terminal. Une phase SFT sur des traces d'outils et des évaluations en
sandbox restent nécessaires. L'exécution de code doit rester limitée à
des outils autorisés, avec quotas, délais et isolation.
